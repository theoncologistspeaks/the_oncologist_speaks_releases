# The Oncologist Speaks — Releases

Official release files for **The Oncologist Speaks**, a chemotherapy cardex
reference app for Windows and Mac.

This repository holds only the built app installers, used by the app's
auto-update feature. It contains no source code, no patient data, and no
regimen data.

Access to the app itself is by activation key. Contact
theoncologistspeaks@gmail.com to request one.
